### 머신러닝
1. 지도 학습
   1. Label이 있는 Feature을 학습시키는 방법
   2. 지도 학습 유형: 회귀(숫자), 분류(범주)
2. 선형 회귀: 데이터에서 직선의 방정식을 찾다.
   1. 예측을 하나의 직선으로 하는 가장 간단하고 직관적인 방법
   2. 모델: "가설"이라고도 부른다.
3. 비용 함수(Cost Function): 모델이 얼마나 잘 예측하는지 나타내는 점수
   1. 이 점수가 낮을수록 모델의 성능이 좋다.
4. 회귀: 정규 방정식
   1. 복잡한 미분 방정식을 풀어서 한 번에 정답을 계산해내는 방법
   2. 장점: 데이터의 특성이 적을 때 빠름
   3. 단점: 데이터의 특성이 많으면 느림
   4. 단점: 역행렬이 없으면 계산을 못함
5. 경사 하강법: 최적의 파라미터를 점진적으로 찾아 나가는 방법 / *파라미터가 뭐지?*
   1. 비용 함수의 기울기가 0이 되는 지점이 가장 비용이 낮은 지점
   2. 학습률 설정
      1. 학습률이 너무 크면, 보폭이 너무 커서 반대편으로 올라갈 수 있음
      2. 너무 작으면, 너무 오래 걸림
      3. 적절한 학습률을 찾는게 중요하겠군
   3. 경사 하강법의 지역 최소값 문제
      1. 시작 위치가 랜덤이므로, 더 깊은 계곡(전역 최솟값)이 아닌 바로 옆의 작은 웅덩이(지역 최솟값)에 빠질 수 있음
      2. 빠진 후 그곳을 최저점으로 착각할 수 있는 것임.
   4. 기울기: 전체 데이터가 만들어내는 평균적인 오차의 기울기
   5. 이터레이션: 데이터의 일부 혹은 전체(batch)를 보고 기울기를 판단?
   6. 허용 오차: 학습 조기 종료 조건
      1. 타협 조건임.
      2. 모델의 오차 감소량이 매우 작아지면, 성능 향상 효율이 저하됨
      3. 이 부분에서 타협하고 학습을 멈추는 것임
6. 경사 하강법의 종류
   1. 배치 경사 하강법(Batch Gradient Descent)
      1. 전체 데이터를 훑어보고 기울기를 계산 / 정확하지만 느림
   2. 확률적 경사 하강법(SGD, Stochastic Gradient Descent)
      1. 하나의 데이터만 보고 바로 기울기를 계산 / 빠르지만 불안정함
   3. 미니배치 경사 하강법
      1. 적당한 수의 배치(batch)만 보고, 기울기를 계산 / 속도와 안정성을 모두 잡음
      2. 배치 수는 정해진 답이 없음. 실험적으로 구해야 함.(귀납적)
7. 정규 방정식 vs 경사 하강법
   1. 현대 AI의 99%는 경사 하강법 계열로 학습함
### 로지스틱 회귀
1. 선형 회귀의 단점
   1. 예측값이 0과 1을 벗어날 경우
   2. 이상치가 너무 클 경우
   3. 다중 분류에서 잘못된 관계를 학습함
      1. 예시: 개=1, 고양이=2, 새=3으로 표현하면 개와 새의 중간은 고양이가 됨.

3. 시그모이드 함수: 선형 회귀의 예측 결과를 0과 1사이의 확률 값을 압축함.
4. 로지스틱 회귀: 선형 회귀의 결과를 시그모이드 함수에 넣음.
   1. MSE를 사용하지 않음. 이진 교차 엔트로피를 사용함 / 이유는 기울기의 안정성 때문임

6. 로지스틱 회귀 완성: 선형 회귀 + 시그모이드 함수 + 이진 교차 엔트로피(BCE)
7. 다중 분류 문제에서는 소프트맥스 함수를 활용함
8. 소프트맥스 함수: 점수를 확률로 바꾸는 마법

   2. 말이 어려울 수 있음.
   3. 모델의 예측 점수가 A:2,B:1,C:0.1이면,
   4. 소프트맥스 통과 후에는 A:0.7,B:0.2,C:01로 변환함
   5. 그러니 A가 70% 확률로 나타나는 것임
9. 소프트맥스 회귀
   1.  결론적으로, 다중 클래스 분류 문제는 다음과 같은 조합으로 해결함
   2.  선형 회귀 + 소프트맥스 함수 + 범주형 교차 엔트로피

# 교수님의 강의- AI & 기계학습 방법론 1 선형회귀(Linear Regression)
1. 단순선형회귀(Simple Linear regression)
  1. 한 개의 설명변수(X)와 하나의 반응변수(Y) 사이의 선형(직전)관계를 찾는 방법  
  2. 목표: 데이터를 가장 잘 설명하는 직선을 찾아 예측에 활용
2. 최소제곱법(least squares)
   1. 모듈의 기울기와 절편을 구하는 방법임.
   2. 실제 관측값과 예측값의 차이(잔차, residual)를 제곱해 합한 값RSS, (잔차제곱합)을 최소화하는 방법
   3. (참고)RSS를 미분해서 0인 지점이 최소 기울기와 절편임!
   4. 공식을 이용해 RSS를 최소화하는 기울기와 절편을 구할 수 있다.
3. 단순선형회귀 결과 해석
   1. Coefficient(계수): 기울기와 절편의 실제 값
   2. Std.Error(표준오차): Coefficient의 불안정성(오차 범위) / 다른 데이터를 투입해서 회귀분석을 시행했을 때 기울기 값이 얼마나 변하는지 나타내는 지수
      1. 값이 작을수록 기울기 추정치가 정확하다고 봄.
   3. t-statistic(t-통계량): Coefficient / Std-Error. 계수를 표준오차로 나눈 값임. 통계적 신뢰성
      1. 절댓값이 2 이상이면 유의미한 영향력이 있다고 봄.
   4. p-value(유의확률): 임의의 참 함수의 기울기가 실제로는 0일때, 내가 계산한 Coefficient 기울기 값(>=)가 나올 확률
      1. 판단 기준은 보통 0.05임. if p > 0.05: 우연으로 발생했을 가능성이 높음. 모델에서 제거를 검토함
4. 다중선형회귀
   1. 독립 변수(Feature)가 여러 개 존재할 때 사용하는 회귀 분석 기법
5. 다중선형회귀: 계수 추정과 예측
   1. RSS가 최소일 경우가 파라미터의 최적 추정치
   2. (참고)최소일 경우의 계수 추정은 행렬 표현으로 유도한다.
   3. (참고)행렬 표현으로 RSS는 2차식으로 표현된다.
   4. (참고)미분해서 0이 되는 값이 우리가 찾는 바로 그것이다.
   5. (끔찍한 교수님의 말)행렬 표현 -> close function까지 손으로 해보라고 한다. 3일이면 된다고 한다.
   6. (끔찍한 교수님의 말)하루 몇시간이면 되고, 스스로의 한계를 정하지 말라고 한다.
6. 다중선형회귀 결과 해석
   1. Coefficient: feature별 기울기와 절편
   2. Std.Error: featrue별 오차 범위
   3. t-statistic: feature별 실제 영향
   4. p-value: feature별 유의미할 확률
7. 모든 선형회귀 모듈에도 교차검증이 필요하다
8. 선형회귀를 통해 대답할 수 있는 질문들

# 로지스틱회귀
1. 분류(Classification)
2. 분류 문제에 선형회귀를 써도 될까?
   1. 선형함수는 예측 확률이 0보다 작거나 1 보다 클 수 있어 쓰기 부적절함
3. 선형회귀의 대안: 로지스틱 회귀(Logistic Regression)
   1. 시그모이드 함수를 활용해 0~1범위 내 확률값 예측 보장
   2. 순서가 없는 범주를 확률로 직접 예측하는 적절한 분류 방법
4. 로지스틱 회귀의 모형식
   1. 시그모이드 함수: 0~1사이만 나오는 1/(1+e^-z)
   2. *3개 이상의 다중 분류에서는 Softmax 활성화 함수를 사용한다.*
   3. 시그모이드 함수에 선형회귀 식을 대입한다(합성함수)
   4. 확률 표기 p(x)를 활용해 이 식을 표현한다.
   5. 로지스틱 회귀의 모형식이 된다.
5. 로지스틱 함수와 선형회귀의 관계
   1. 관계 해석을 위해 odds와 로짓 변환을 사용한다.
   2. Odds: 성공확률 / 실패확률
   3. logit: log(성공확률 / 실패확률)
   4. 로지스틱 함수의 logit 을 하면 선형회귀 식이 나온다. / *신기하다*
6. 우도(Likelihood)
   1. 손실 함수를 구하기 위한 계산 과정의 산출물임
   2. 분류에서는 MSE를 사용하기 힘듦. 그렇게 되면 그래프가 심한 Non-convex 함수가 됨
   3. 확률을 추정하는 모델을 결정했으니, 파라미터를 추정하는 방법이 필요하다.
   4. 우도란 현재 확률 함수가 데이터를 얼마나 잘 설명하는지를 나타낸 지표이다.
   5. 로지스틱 회귀와 같은 이진 분류 문제에서 우도를 최대화한다.
   6. 1이 정답인 얘들은 1에 가깝게 예측하고 싶다.
   7. 0이 정답인 얘들은 0에 가깝게 예측하고 싶다
   8. 최대화를 한 후 log 변환을 한다.
   9. 둘 다 단조(monotone)증가 함수이다
   10. 따라서 log-likelihood의 최대값의 우도가 로지스틱 회귀 함수의 최대값 우도이다.
   11. -log-likelihood가 손실 함수이다.
7. 로지스틱 회귀 결과 해석
   1. Coefficient: feature별 Log-odds 공간 안에서의 기울기 / 시그모이드, 소프트맥스 내부의 선형 회귀 함수의 기울기
   2. Std.error
   3. z-statistic(z-통계량): 대용량 데이터에서는 표준정규분포(Z-분포)에 수렴하므로, z-통계량을 사용
   4. p-value

###  shallow 네트워크
1. 활성화 함수(activation function)
   1. 위대한 발견: 1989, George Cybenko / 활성화 함수를 가진 은닉 노드를 사용하면 세상에 존재하는 모든 연속적인 곡선/복잡한 함수를 오차 없이 똑같이 시늉(근사)할 수 있다.
   2. ReLU: 들어온 신호가 음수면 0으로 만들고, 양수면 그 숫자 그대로 통과시킴
   3. 입력 구간을 나눠 조각별 선형 함수를 만듦
2. shallow 네트워크: hidden units
   1. $\theta$a[b + b2x]
   2. 활성화 함수 a는 모두 동일하다
   3. $\theta$와 [b + b2x]는 히든 유닛마다 다르다.
   4. h1, h2, h3
   5. 히든 유닛들(뉴럴 유닛)을 각 단계별 계산해보자.
   6. 그 후 $\theta$를 활성화 함수 값에 곱한다!
   7. 그 후 히든 유닛들을 더해서 최종 그래프를 뽑는다!
   8. 히든 유닛들만큼 꺾인점이 생긴다!
3. shallow 네트워크로도 임의의 연속함수를 충분히 표현 가능하다! 단, Hidden unit을 충분히 많이 갖는다면!
4. 2개 입력 네트워크: 단계별 계산
   1. 면으로 표현된다. 색이 다르다.

### Deep 네트워크(2개 이상)
1. 합성 네트워크의 층별 출력
   1. 위의 shallow 네트워크 함수에 shallow 네트워크를 집어넣은 합성함수를 만든다고 생각해보자.
   2. 결과는, 더욱 요동치는 그래프의 함수가 나오게 된다.
   3. 인공신경망에서, 꺾인 선이 많아진다는 뜻은 표현력이 풍부해짐을 뜻한다.
   4. 이 방법을 사용하면 적은 파라미터로도 풍부한 표현력을 가질 수 있다.
2. 2층 네트워크의 수식 표현
   1. 하나의 shallow 네트워크가 그 뒤 함수의 히든 유닛에 들어간다.
   2. 적은 수의 파라미터로도 복잡한 표현이 가능하다

### 신경망 적합(Fitting)
1. 손실함수(로스 함수)
2. 1D 선형회귀 예
3. 경사 하강법
   1. 손실 함수의 값이 줄어드는 방향으로 파라미터를 이동하는 과정
   2. 로스 함수를 구한 후 미분, 기울기 값이 줄어드는 방향으로 파라미터를 이동
   3. *로스 함수는 무조건 2차함수인가?*
   4. *Gemini:아니다. 기울기만 구할 수 있는 함수면 된다.*
   5. 미분값의 반대방향으로 이동한다
   6. 미분값이 크면 큰 스텝으로 이동한다
   7. 기울기는 편미분으로 계산한다.
   8. 편미분은 모든 파라미터에 대한 미분값이다.
   9. 경사 하강법의 목적은 Global minimum을 찾는 것.
4. (교수님의 끔찍한 말씀)미분도 꼭 해보라고 말씀하신다. 자기가 설정한 벽을 부수라고 하셨다.
5. 경사 하강법을 활용한 파라미터 업데이트
   1. 데이터
   2. 손실 함수 3D 그래프
   3. 손실 함수 등고선(2D)
   4. 선형함수의 업데이트
6. Convex vs Non-convex 최적화 문제
   1. Convex: 곡선이 항상 U자처럼 아래로 볼록. / 최적화가 쉽다.
   2. Non-convex: 봉우리, 골짜기, 오목한 구간이 섞인 모양 / 최적화가 어렵다
   3. 뉴럴 네트워크는 유감스럽게도, 대부분 Non-convex다.
7. 경사 하강법의 단점
   1. Non-convex 문제에서 지역(local) 최소점에 빠지기 쉬움
   2. 매 스텝마다 전체 데이터에 대한 미분값을 구하여 업데이트함
   3. 대안: 전체 데이터를 한번에 쓰는 대신, 무작위로 선택한 데이터 샘플 사용
   4. 그것이 확률적 경사 하강법임.
8. 확률적 경사 하강법
   1. 지금은 AdamW가 대세다.
   3. Local 최소점에서 빠질 위험이 상대적으로 적음
   4. 무작위 샘플 데이터를 활용한 미분으로 경로의 무작위성이 있음
   5. 노이즈한 스텝을 밟지만 안전함
   6. 노이즈가 있지만 타당한 업데이트
      1. 점진적 최적점 방향으로 수렴
   7. 계산 비용 절감. 작은 배치만 사용하므로 반복당 연산량이 적음
   8. 수렴 특성: 지그재그 진동하며 전역 최솟값 근처의 좋은 해에 도달할 수 있음
9.  네트워크 파라미터의 미분값을 어떻게 구할까?
   1.  레이어(작은 함수)별로 파라미터들이 존재함. 서로 영향을 미침
   2.  핵심 아이디어: 합성함수의 변화율 = 바깥의 변화율 * 안쪽의 변화율
10. 역전파(Backpropagation)
    1.  출력 오차를 기준으로 그래프를 거꾸로 따라가며 연쇄법칙으로 각 노드(파라미터 포함)의 미분값을 계산하는 절차
    2.  각 단계별 계산을 분해
    3.  각 layer별 값을 계산
    4.  각 layer별 값에 대한 출력 손실의 미분을 구함
