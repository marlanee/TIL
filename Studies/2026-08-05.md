1. 데이터가 왜 중요한가?
  - 머신러닝은 직접 코딩 x, 데이터에서 규칙을 학습
  - 데이터의 분포와 관계가 머신러닝의 학습 결과를 결정
  - Feature(피처, 특정): 모델이 예측에 사용하는 입력정보 / 예측, 판단의 근거 및 단서
  - Label (라벨, 목표값): 모델이 예측하려는 정답 / 학습의 목표값
2. ML 실생활 예시
  1. 유튜브 추천
     1. Feature: 각 영상들의 정보, 사용자 정보
     2. Label: 영상에 대한 사용자 피드백(시청 여부, 좋아요 클릭 여부)
     3. Feature가 input이 되고, Label이 output이 된다.
  2. 스팸메일 분류
     1. Feature: 메일 제목, 발신자, 단어 빈도
     2. Label: 스팸 or 정상

### 모델과 가설 공간
교수님이 말씀하시길, 개념이 탄탄히;기본기가 중요하다고 했다.  
1. 학습 (Learning): 입력 (Feature) -> 출력(Label) 관계를 찾는 과정
2. 가설 공간 (Hypothesis Space)
   - 관계를 표현할 수 있는 모든 후보 함수들의 모음

   - 가설 공간에 속한 특정 함수 f

feature가 하나 더 생겼다. z축이 생겼다. x, y가 feature가 되었다.  
```Income = f*(미지의 참 함수) + e(엡실론)```

### 일반적 용어 정리 및 모델 가정
1. 모델(함수형): Label = f*(feature) + e(엡실론)
2. 측정오차 e(엡실론)은 피쳐 X와 독립적이다. X와 e의 크기는 무관하다.
3. 엡실론의 평균 기대값은 0이다.

지도 학습: 처음 보는 문제도 잘 푸는 AI 만들기  
정의: feature + label을 가지고 예측 규칙을 배우는 방법  
목표: 훈련 데이터 뿐만 아니라, 처음 보는 데이터에서도 예측 성능 향상  
예시 1: 어제까지의 고객 데이터로 "내일 이탈할 고객" 미리 알기  
예시 2: 기존 거래 사기(Fraud)데이터로 새로운 사기 탐지

### 지도학습(Supervised learning)이란?
정답 라벨이 있는 훈련 데이터를 사용해 예측 모델을 학습하는 방법  
목표: 훈련 데이터로 학습한 모델이 새로운 데이터에서도 정확한 예측을 수행  

---
### 지도학습의 종류 (회귀 vs 분류)
1. 회귀(Regression): 예측하고 싶은 결과값이 숫자일 때 사용
2. 분류(Classfication): 예측하고 싶은 결과값이 범주일 때 사용 / 스팸메일, 동물 분류 등
3. 손실 함수(Loss Function): 모델의 예측이 정답에서 얼마나 벗어났는지를 하나의 숫자로 나타내는 함수
   - 학습이란, 이 숫자가 작아지는 방향으로 모델을 조금씩 고쳐 나가는 과정
   - 평균제곱오차(MSE): 회귀에 사용. 정답과 예측의 차이를 제곱해서 평균낸 값
     - 치명적인 실수를 피하기 위해 제곱값을 사용한다.
   - 교차 엔트로피(Cross Entropy): 분류에 사용. 정답 범주에 얼마나 높은 확률을 주었는지 측정
   - *궁금한게 있다. 왜 회귀와 분류에 저 함수들이 사용된거지?*
4. 회귀: 입력으로부터 숫자를 얼마나 정확히 예측할까?
   1. 회귀인지 분류인지는 출력되는 label에 타입에 따라 결정된다.
5. 회귀 오류: 평균제곱오차(MSE)
6. 회귀 설명력: R^2 (결정계수)
   1. 평균만 쓰는 단순한 예측보다 예측 모델이 얼마나 정확한지 나타내는 지표
   2. 0~1 사이 값을 가지며, 1에 가까울수록 설명력이 높다.
7. MSE vs R^2
   1. MSE: 실제 데이터 단위, 0에 가까울수록 좋음
   2. R^2: 직관적임
8. 분류: 입력 특성으로부터 출력이 범주값(카테고리)로 나타나는 예측 문제
9. 분류 정확도: 범주는 MSE나 R^2를 사용하기 어렵다.
   1.  정확도: 전체 예측 중에서 올바르게 맞춘 예측의 비율
   2.  그런데, 불균형 데이터(양성 1%, 음성 99%)에서는 전부 음성이어도 정확도가 99%임
   3.  따라서, 다른 지표도 함께 봐야함 / *어떤 지표?*
10. 혼동행렬(Confusion Matrix)
    1.  정밀도: 양성 판정 중 진짜 양성의 비율
    2.  재현율: 진짜 양성 가운데 잡아낸 예측 양성 비율
    3.  F1-score: 정밀도와 재현율의 조화평균. 높으면 좋다.
    4.  교차 엔트로피: 정답에 준 확률이 높을수록 손실이 작아짐. 확률이 낮으면 손실이 급격히 커짐
11. 학습의 목적: 새로운 데이터에서 예측하기
    1.  훈련이 잘 됐는지 어떻게 확인할까? (모델 성능 평가)
    2.  반드시 모델이 처음 보는(학습에 사용되지 않은) 데이터로 평가해야함
    3.  모의고사 100점이어도 수능 20점이면 원하는 대학에 들어갈 수 없음.
12. 오버피팅(overfitting): 훈련 데이터의 우연한 패턴, 잡음까지 외워버려서 훈련에서는 잘 맞지만 테스트에서는 성능이 나빠지는 현상
    1.  목격되는 현상: 훈련 오류 급격히 낮음. 테스트 오류 높음/요동
13. 언더피팅: 모델이 단순하거나 학습이 완료되지 않음
    1.  목격되는 현상: 오류 큼

## 평가
### 테스트 성능 평가
1. 훈련 오류 vs 테스트 오류
   1. 훈련 오류: 모델을 학습시킨 같은 데이터에 다시 적용해 계산한 오류
      1. 예전 수능 풀기
   2. 테스트 오류: 학습에 쓰지 않은 새 관측치에 대해 모델을 적용했을 때의 평균 예측오류
      1. 진짜 수능 풀기
   3. 훈련 오류는 테스트 오류와 다르다. 훈련 오류는 테스트 오류를 과소평가한다.
2. 테스트 예측 오류 계산: 이상적으로는, 충분히 큰 별도의 테스트 데이터셋이 있으면 된다. 현실은 어렵다.
3. 대안: 재표본화(resampling)을 통한 테스트 오류 추정
   1. 데이터를 나눠 여러번 훈련 -> 평가 진행. 오류 줄임
4. 검증셋(Validation Set) 방법
   1. 가용 샘플들을 무작위로 훈련셋과 검증셋으로 분할
   2. 학습은 훈련셋에서, 성능평가는 검증셋에서 수행
   3. 단점: 표본에 따라 검증 기반 테스트 오류 추정치가 매우 가변적
5. K-겹 교차검증(K-fold Cross-Validation)
   1. 테스트 오류 추정의 표준적 접근
   2. 중요: 데이터를 먼저 셔플링한 뒤 총 n개의 데이터를 겹치지 않는 K개 그룹으로 분할
6. K-겹 교차검증 오류 계산
7. Leave-One-Out 교차검증: K-겹 교차검증과 비슷. 그러나 검증셋이 1개임

## 비지도 학습
레이블(정답) 없이 데이터의 구조, 패턴, 집단을 찾아내는 학습  

1. 비지도 vs 지도학습
   1. 지도학습: 입력 + 라벨(정답)로 예측 모델 학습
   2. 비지도학습: 입력만으로 구조 학습
2. 클러스터링(Clustering): 데이터 안에서 하위 집단(클러스터)을 찾는 기법들의 총칭
   1. 집단 내부는 서로 유사, 집단 간은 상이하도록 데이터를 분할
3. 두 가지 대표 클러스터링 기법
   1. K-평균(K-means): K(클러스터 수)를 미리 정해 분할
   2. 계층적 군집(Hierarchical): K를 사전에 고정하지 않음
4. K-means 클러스터링 알고리즘
   1. 초기화: 관측치들에 무작위로 1 ~ K 클러스터를 임시 부여
   2. 반복(할당이 더 이상 바뀌지 않을 때까지)
      1. 각 클러스터의 중심(centroid) 계산(특성 평균 벡터)
      2. 각 관측치를 가장 가까운 중심의 클러스터에 재할당(거리 예 = 유클리드)
   3. 특성: 중심점과의 평균 거리가 줄어들어, 반복시 결과가 더 좋아짐 / 그러나, 최적 해를 찾는건 아님
   4. K 개의 서로 색이 다른 중심들이 생기고, 그 중심들에 가까운 클러스트들을 그 색으로 물들임
   5. 클러스터 초기화로 인해, 다시 시도하면 결과가 달라질 수 있음
   6. 따라서, 여러번 시도해서 최솟값을 골라야 함
5. 계층적 군집(Hierarchical Clustering)
   1. 클러스터 수 지정이 필요 없음
6. K-means 클러스터링 vs 계층적 군집
   1. 계층적 군집은 K를 고정하지 않고 전체 구조를 덴드로그램으로 제공
   2. 계층적 군집이 K-means보다 연산량이 많음
7. 계층적 군집 결과 예시: 덴드로그램에서 수평선 높이(거리)를 기준으로 가위질하여 K개 군집을 얻음
8. 계층적 군집 알고리즘(상향식)
   1. n개 관측에 대해 쌍별 비유사도 계산, 각 관측치를 하나의 클러스터로 시작 / *유사도가 뭔데?*
   2. i개 클러스터 간 쌍별 비유사도를 모두 계산해 가장 유사한 두 크러스터를 병합
   3. 병합 후 남은 i-1개 클러스터 사이의 새 비유사도를 다시 계산
   4. 쉽게 말하자면, 가장 가까운 클러스터끼리 계속 병합한다!
9. 계층적 군집의 링크 유형
   1.  Single(최소 거리) 링크: 두 클러스터 내부 가장 가까운 데이터 쌍별 거리 최소값
   2.  Complete(최대 거리) 링크: 최소와 반대.
   3.  Average(평균 거리) 링크: 쌍별 거리 평균
