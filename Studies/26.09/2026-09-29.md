### SWEA 3289 서로소 집합

- 질문: find(x)에서 왜 단순히 대표자만 찾아서 반환하는 게 아니라,
``` parent[x] = find(parent[x]) ```
처럼 경로 압축까지 하는 걸까?

1. union 함수를 사용할 때 집합이 합쳐져서 B의 대표자가 바뀌고, 나중에 대표자가 바뀐 집합들도 union에 속해있다는 것을 표기해야되는 코드기 때문이야 / -> 아님
*union으로 집합이 합쳐지면서 대표자가 바뀔 수 있기 때문에 find()가 최종 대표자를 재귀적으로 찾아가고, 그 과정에서 각 노드의 parentt를 최종 대표자로 갱신해서 이후 탐색을 빠르게 한다. 이 과정이 없다면, 4 -> 3 -> 2 -> 1 같이 대표자를 찾으려고 전부 따라가야 한다*

- 다음 질문. union(a, b)를 할 때 왜 `그냥 parent[b] = a` 하면 안 되고, 
``` python
ra = find(a)
rb = find(b)
parent[rb] = ra 
```
처럼 대표자끼리 연결해야 하는지 설명해봐.

1. parent[b] = a를 하면 그저 b를 a union에 넣는것과 마찬가지야. b의 대표자를 연결해야 b가 속한 집단을 a 집단에 합칠 수 있어.

- find(a) == find(b)라는 조건은 정확히 무엇을 의미할까? 그리고 SWEA 3289에서는 이 조건을 어떤 명령에서 사용하는지 설명해봐.

1. 그 조건은, b가 a의 집단에 속해있다는 의미야. 3289 문제에서는 정확히 이 상황에서 사용해. 집단에 속해있는지 여부를 판별하는 문제였으니까.

- 마지막으로 하나만 더 확인하자.
find() 함수에서
if parent[x] != x:    
parent[x] = find(parent[x])
return parent[x]

여기서 parent[x] == x인 경우가 왜 대표자라는 뜻인지 설명해봐.

1. parents[x] == x 라는 뜻은 자기 자신 위로는 아무도 없다는 뜻이야. 즉, 대표자라는 뜻이지
