# AI 실습
1. MLP의 한계
   1. Flatten 과정에서 1차원 벡터로 펼쳐짐. 연관성 상실
   2. 고해상도 이미지 입력시 느린 학습 속도, 과적합 위험
2. CNN의 등장
   1. 이미지를 펼치는 대신, 작은 필터를 사용해 이미지를 훑으며 특징을 찾아냄
   2. 2차원 그대로 Filter를 이용해 이미지의 각 부분을 찍어보며 특징을 추출
   3. 이미지 전체에 동일한 필터 가중치를 적용해 파라미터 수를 줄임
   4. CNN의 목표는 이미지의 특징을 가장 잘 뽑아내는 필터를 찾는 것임.
3. 합성곱 신경망(Convolutional Neural Network)
   1. 필터가 이미지 위를 이동하며, 겹치는 영역의 픽셀 값과 필터의 가중치를 곱하고 모두 더함
   2. 만약 필터가 64개라면, 각각 다른 특징을 감지하는 64개의 서로 다른 특징 맵이 만들어짐
   3. 필터 내부의 숫자는 파라미터 딥러닝으로 학습됨
   4. PyTorch에서는 nn.Conv2d를 사용하여 합성곱 계층을 정의함
   5. `nn.Conv2d(in_channels=3, out_channels=6, kernel_size=5)`
4. CNN의 핵심 연장: 풀링(Pooling)
   1. 합성곱 연산을 통해 얻은 특징 맵의 크기를 줄이는 과정
   2. 계산 파라미터 수 감소, 노이즈로 인한 과적합 방지
   3. PyTorch에서는 nn.MaxPool2d를 사용하여 최대 풀링 계층을 정의함
5. 완전 연결 레이어
   1. CNN의 마지막 단계에서, 추출된 특징들을 종합하여 이미지의 클래스를 분류함
6. 모델 평가하기
7. 손실 함수: nn.CrossEntropyLoss
8. 옵티마이저: optim.SGD
9. 학습 루프는 다음과 같음
   1.  모델 훈련은 다음 과정을 수없이 반복(에폭, Epoch)하는 것
   2.  DataLoader에서 미니배치 데이터를 가져옴
   3.  기울기 초기화 (칠판 지우기): optimizer.zero_grad()
   4.  순전파: outputs = net(inputs)
   5.  손실 계산: loss = criterion(outputs, labels)
   6.  역전파: loss.backward()
   7.  가중치 업데이트: optimizer.step()
10. 모델의 진짜 실력 확인하기
    1. 테스트 데이터를 모델에 입력하여 예측값을 얻음
    2. torch.max 함수를 사용함
    3. 오답노트를 사용해서 다음 학습의 방향성을 결정

### 2교시(전이 학습, 모델 성능 향상)
### 전이 학습
1. 모델을 처음부터 학습시키는 건 현실적이 어려움이 있음
2. 해법은 전이학습임
3. 거인의 어깨에 올라타는 방법이라고 생각하면 됨
4. 대규모 데이터셋으로 이미 학습된 모델의 가중치를 새로운 모델의 활용하는 것임
5. 선, 모서리, 질감, 색 변화를 찾아내는 능력은 똑같이 필요함
6. 이 부분을 빌려오는 것임
7. 특징 추출부는 그대로 가져오고 분류하는 부분을 떼어내고 새로 다는 방식을 사용함
### 전이학습 종류
1. Linear Probing(=특징 추출)
   1. 특징 추출부의 가중치를 고정, 새로운 분류층만 학습
   2. 가중치 동결(Weight Freezing), `param.requires_grad = False`
      1. 합성곱 층들이 업데이트되지 않도록 막는다
      2. 잘 만들어진 특징 추출부는 건드리지 않겠다!
   3. 분류층 교체 (Head Replacement)
   4. 장점: 압도적인 학습 속도(전체 파라미터 중 1% 미만, 분류층), 적은 데이터로 가능, 성능의 베이스라인
3. 학습을 10분의 1도 안 했는데, 정확도가 많이 올랐다. 
4. 역시, 거인의 어깨 위에서 세상을 봐야 한다.
### Fine-tuning
1. 동결했던 특징 추출부도 포함해서 전체 파라미터를 다시 학습시킴
2. 단, 가져온 사전 학습 모델은 정교하므로, 학습률을 매우 낮춰서 학습을 진행함
   1. 기존의 공부 방법을 유지하면서 더 배워나가는 느낌인 듯
3. Fine-tuning을 왜 함? -> 내가 가진 데이터만의 특징에 더 최적화하기 위함임
### 전이학습 한계
1. 원본과 완전히 다른 도메인일 경우 효과가 제한적일 수 있음
2. 사전학습 모델의 편향까지 함께 가져온다
3. 라이선스 확인 필수 -> 상업적 이용 조건이 모델마다 다르다.
### 모델 성능 향상
1. 데이터 증강(Data Augmentation)
   1. 학습 데이터에 무작위적 변환(회전, 자르기, 뒤집기 등)을 가하여 학습
   2. 장점: 과적합 방지, 일반화 성능 향상, 데이터 증가
   3. 단점: 데이터 본질 훼손 가능, 학습 난이도 및 시간 증가
   4. 따라서 데이터의 성격을 보고 증강을 사용할지 말지 정해야함
2. 학습률 스케쥴러(Learning Rate Scheduler, LR Scheduler)
   1. 특정 시간이나 Epoch에 따라 학습률을 조정하는 방법
   2. 장점: 세밀한 손실 감소, 성능 극대화
   3. 단점:
3. Optimizer vs LR Scheduler
   1. Optimizer: 운전대를 돌리는 사람, 매 배치마다 개별 파라미터 조정
   2. LR Scheduler: 제한 속도 조정 표지판, 매 에포크마다 학습률 조정

### 딥러닝 및 이미지 파운데이션 모델
1. 파운데이션 모델이란?
   1. 하나의, 믿고 쓸 수 있는 모델!
   2. AI 모델: 학습 때 보지 못했던 데이터에 대해서도 작동이 요구되는 함수
   3. 이상적인 AI모델: 이 세상의 모든 데이터를 학습한 모델. 뭐든 것을 답변해주는 검색 엔진
   4. 현실적인 기계학습 모델: AI모델에 데이터를 패턴화 하여 압축
2. 기존 AI모델 vs 파운데이션 모델
   1. 기존 딥러닝 개발 패러다임: 아기와 같이 기본적인 것들부터 배워 나가야함
   2. 파운데이션 모델 패러다임: 거대 모델(커다란 뇌) + 대규모 데이터 학습(많은 지식과 경험) 기반
3. 파운데이션 모델의 특징
   1. 대규모 사전학습: 트랜스포머 모델 + 대규모 언어 데이터 학습 / 쉬운 데이터 수집
   2. 적응성: 높은 미세조정 성능
   3. 범용성: 다양한 작업, 한정되지 않는 출력 지원
4. 파운데이션 모델 등장에 따른 AI 모델 개발의 변화
   1. 과거: 매번 모델을 태스크 별로 새로 학습
   2. 현재: 잘 학습된 모델을 얼마나 잘 활용하느냐가 핵심
   3. 적응 활용: 프롬프트(엔지니어링, 튜닝). 전이학습, 적응 학습
      1. Zero-shot / Few-shot, Fine-tuning

### 데이터 효율화를 위한 합성 데이터 사용

2. 지식증류: 높은 성능의 무거운 모델(선생님)을 모방하도록 가벼운 모델(학생)을 학습하는 방법
   1. 선생님 모델이 예측한 soft-label 값과 학생 모델의 예측 값이 가까워지도록 학습 유도
3. 파운데이션 모델들을 툴로 활용하는 방법: InstructPix2Pix (중요!!)
   1. 명령에 따라 이미지 편집을 수행하는 모델
   2. 상세 설명 없이 명령만으로 편집 수행
   3. 지시사항 기반 이미지 편집을 지도학습 문제로 전환 (입력 데이터-정답 쌍 필요)
   4.
