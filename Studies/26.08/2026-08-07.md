# MLP
1. 왜 MLP인가? - 딥러닝의 등장
   1. 머신러닝의 한계와 딥러닝의 등장
   2. 고전적 머신러닝: 사람이 직접 데이터의 중요한 특징을 가공해서 알려줘야 함
   3. 한계점: 이미지나 텍스트 같은 비정형 데이터 처리가 비효율적임
   4. 딥러닝의 등장: 인간의 뇌 신경망 구조에서 영감을 받아 인공신경망 기반 딥러닝이 등장함
2. 모든 것의 시작, 퍼셉트론 - 1957, 프랑크 로젠블랫
   1. 기계도 학습할 수 있다: 퍼셉트론의 등장
   2. 퍼셉트론 구성요소: 입력, 가중치, 가중합, 활성화 함수
3. 퍼셉트론의 원리
   1. 퍼셉트론은 결국 데이터 사이에 직선 하나를 그어서 두 그룹을 나누는 것과 같음
4. 퍼셉트론의 한계와 AI의 겨울
   1. 여러 feature가 투입될 경우 하나의 직선으로 해결 불가
   2. 해답: 역전파 -> 다층 신경망(딥러닝) 학습으로 이어짐
5. 층을 쌓으면 XOR이 풀린다: 더 복잡한 모양도 나눌 수 있다.
6. 활성화 함수(신호를 켜고 끄는 스위치)
   1. 유닛에 비선형성을 추가하는 함수.
7. MLP의 학습 과정
   1. 순전파(Forward Propagation): feature로 결과를 계산하는 과정. 국소 미분값을 저장함
   2. 손실 함수 계산(Loss Function): 예측 결과와 실제 정답을 비교하여 오차를 숫자로 계산
   3. 역전파(Back Propagation): 범인 찾기. 손실의 원인을 찾아 거꾸로 추적함. 
   4. 옵티마이저
### 성능 향상
1. 과적합과 규제
   1. 과적합: 모델이 훈련 데이터만 외워서 실제 데이터 예측값이 형편없어지는 현상
   2. 규제: 과적합을 막기 위해 모델에 제약을 거는 기법임
2. 훈련 종료 시점 정하기
   1. 학습 루프 (Trainig loop): 순전파 -> 손실 계산 -> 역전파 -> 가중치 업데이트 반복 과정이 훈련의 전부
   2. 조기 종료 (Erly Stopping): 검증 데이터로 검증을 하고 손실 함수가 점점 커지면 과적합이라고 판단 후 훈련 종료
3. 옵티마이저 (Optimizer): 머신러닝에서 손실 함수의 값이 최소가 되는 최적의 가중치를 찾기 위해 사용되는 알고리즘
   1. 기본적 옵티마이저: 경사하강법
   2. 경사 하강법의 치명적 단점
      1. 학습률이 높은 경우 손실 값이 오히려 커지는 오버슈팅 발생
   3. Adam: 사실상 표준 옵티마이저
      1. 관성(Momentum) 도입: 잠시 지역 최저점에 빠져도 관성의 힘으로 빠져나올 수 있음
      2. 적응적 학습률(Adaptive Learning Rate) 도입: 큰 변화가 있었던 가중치는 조금 건들기.
