### On-device AI 하드웨어
1. On-device에 들어가는 각종 하드웨어들.
   1. 모바일 SoC: 여러 칩이 담당하는 기능을 하나의 칩 안에 몰아서 통합 구현
   2. ONNX: 개발 유연성과 최적화 효율성을 동시에 제공하는 AI 배포의 표준 인터페이스
2. AI 가속기의 구동 특성: 정수 연산만 지원하거나 정수 연산에 효율적
   1. 소형 Device에 들어가는 장치임
3. 일반 양자화와 100% 정수연산 양자화의 차이
   1. 일반 양자화: 소수점을 자름.
   2. 문제점: 스케일링 파라미터가 실수라는 것 -> 스케일링 파라미터 필요
   3. 스케일링 파라미터는 AI 가속기로 구동할 수 없다.
4. 행렬 곱 연산 양자화
   1. 비트 쉬프팅: 스케일링 파라미터를 뭉쳐서 M으로 나타냈으니, M을 별도로 양자화하자!
5. 배치 정규화 계층 폴딩: 과정의 합성 -> 연산 과정 축소
   1. BN계층에서도 실수 연산 필요 -> 폴딩 기법 활용
6. 행렬 곱과 배치 정규화 폴딩 외에 추가적 연산 정수화가 필요함
   1. Softmax
   2. GELU
   3. LayerNorm

# AI 모델 활용 - 테스트 타임 도메인 적응
1. 분포 이동과 테스트타임 도메인 적응(TTA)
   1. 분포 이동: AI 모델이 현실에서 동작할 때, 낯선 데이터를 맞닥뜨리는 현상
   2. 시험 범위 밖의 문제가 출제된 느낌임
2. 테스트타임 도메인 적응
   1. AI가 실제 쓰이는 순간, 테스트 데이터의 분포를 파악하여 모델을 유연하게 적응시킴
   2. 즉, 테스트 데이터를 입력받을 때 모델의 일부를 새 데이터의 통계에 맞게 재조정
3. TENT: 배치 정규화 계층을 테스트 데이터에 최적화
   1. *눈 앞에 보이는 모든 데이터를 학습하는 미친놈임. 썩은 빵도 먹음*
   2. 실제 데이터의 명도나 채도 등 아주 일부만 바꾸는 파라미터만 학습시키는 것임
   3. 그러면 작은 연산으로 정답률을 올릴 수 있음
   4. 역전파를 통해 스케일, 이동값을 미세 조정함
   5. 대규모 가중치는 모두 동결.
4. SAR: 최적화를 더욱 안정적으로
   1. *썩은 빵은 먹지 않는 똑똑한 녀석*
   2. 일부 테스트 데이터가 완전 악질임. 노이즈 많고 이상치. -> 모델 불안정
   3. 이럴 때는 엔트로피(불확실성)가 낮은 테스트 샘플만 선택해서 모델 업데이트에 반영함
### 비전언어모델 기반 TTA 기법
1. TPT(Test-Time Prompt Tuning): 일관성 있는 예측을 돕자!
   1. *노이즈 사진을 보고, 몰라도 자신있게 답하는 이상한 녀석임*
   2. 엔트로피를 로스로 세팅하고 이를 최소화하도록 텍스트 프롬프트를 업데이트
   3. 더 잘 설명할 수 있도록 내재된 프롬프트를 업데이트
   4. 테스트 증강본을 활용하여 업데이트
2. PromptAlign: 학습 데이터와 테스트 데이터를 직접 정렬 시키자!
   1. *노이즈 사진이 온다면, 그럼에도 배운 내용에서만 답하는 똑똑한 녀석*
   2. 텍스트 프롬프트 뿐만 아니라 이미지 프롬프트도 업데이트
   3. 학습 시 얻은 feature 분포와 테스트 feature 분포를 정렬시킴

# 적응적 센싱
### 스케일링의 법칙과 초거대 AI
1. 스케일링 법칙
   1. 모델 크기, 학습 데이터 양, 컴퓨팅 자원이 증가하면 성능이 향상된다.
2. 스케일링의 법칙의 한계
   1. 이 세상에서 일어날 수 있는 모든 경우의 수를 학습 데이터로 준비할 수는 없다.
   2. AI의 진화: LLM, ViT -> 피지컬 AI
   3. 피지컬 AI가 모든 데이터를 수집하면, 데이터가 너무너무 많아진다.
   4. 보완책이 필요하다: 적응적 센싱이 필요하다!
3. 적응적 센싱: 환경에 맞춰서 센서를 조절해서 좋은 데이터만 받음
4. 적응적 센싱을 위한 데이터셋
   1. ImageNet-ES(이미지 분류 태스크): 이벤트가 발생할때만 촬영
   2. SenseShift6D(물체 6D 포즈 추정 태스크)
5. 적응적 센싱 기법: Lens
   1. 센서 파라미터 후보 선택: 최소한의 센서만 켜다가 반응하기.
   2. 이미지 캡쳐
   3. 비전 테스트
   4. 최적의 파라미터 선택
6. Lens vs Auto-Exposure(AE)
   1. Lens: 센서 제어로 모델이 보기 좋은 이미지를 만듦
   2. AE: 사람이 보기 좋은 이미지를 만들기 위한 제어 기법
