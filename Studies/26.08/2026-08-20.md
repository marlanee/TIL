# Post-training (사전 학습)
1. Pre-training 후 모델의 응답: 질문에 대한 대답을 안 함
2. Post-training(사후 학습): 사용자에 맞는 원하는 대답을 도출하기 위함
3. Instruction-tuning
   1. 사전 학습 후 거대 언어 모델은 유저의 의도와 일치하지 않음 -> 파인 튜닝 진행
   2. 사람이 내린 지시문을 따르도록 학습하는 단계
   3. 정답 레이블이 요구됨. 다양한 태스크를 풀 수 있도록 적응시키는게 목표
4. MMLU: 다양한 태스크에서 AI의 성능 지표
   1. 수백가지를 복수 전공한 우리 gemini..
5. 모델의 일부 파라미터만 학습시킬수도 있다.
6. Instruction-tuning은 Pre-training에 비해 많은 데이터가 필요하지 않음
   1. 모델이 그렇게까지 많이 훈련될 필요는 없다.
   2. 나는 푹 자고 공부도 잘한다!
### Reinforcemen Learning from Human Feedback (RLHF)
1. RLHF: 인간 피드백 강화학습
2. RLHF는 pre-trainig과 instruction-tuning보다 더 나은 성능 향상을 제공한다
   1. 롤 모델을 흉내내는 것으로는 롤 모델을 넘을 수 없다.
3. RLHF 주의점: 리워드 모델이 잘 작동하는지 먼저 잘 확인해야 한다.
4. 리워드 모델링의 한계점
   1. 인간의 선호도는 일관성이 부족함
   2. 리워드 해킹은 강화학습에서 자주 발생하는 문제이다.
      1. 이것 때문에 할루시네이션 발생
      2. 인간의 선호도를 학습한 리워드 모델은 더 일관성이 부족하다
      3. *어떤 놈이 그럴싸한 답변에 공감하고 높은 점수를 준거야?*
5. DPO: RLHF에서 RL을 제거하자
   1. Direct Preference Optimization
   2. PPO에서 진화한 방식 (Proximal Policy Optimization)
   3. *PPO: 시험장에서 모의고사 치르게 해서 실시간 점수로 계속 태도 교정함*
   4. *DPO: 우수 모범 답안, 탈락 답안 오답노트를 주고 다이렉트 교육을 시킴*
6. RLVR(Reinforcement Learing with Verifiable Reward): DeepSeek
   1. RLHF에서 수학 문제와 같이 답이 분명한 문제들은 정답 여부로 리워드를 주자.
   2. * 1234코딩,수학,팩트 영역에는 RLVR을 적용해서 보상 해킹 위험을 원천 차단한다.*

### 두번째 강의 / RAG
1. Retrieval-augmented LM: 추론 시 외부 데이터 저장소를 불러와 활용하는 언어모델
   1. *내가 맨날 gemini한테 요구하는 그것이다. 검색 좀 해서 답변하라고.*
   2. 주어진 query와 가장 관련성이 높은 정보를 찾아내는 과정을 거침
2. Information Retrieval
   1. 사용자의 검색 질의(Query)에 가장 관련성이 높은 정보를 제공하는 것
   2. IR의 활용: 웹 검색, 추천 시스템
   3. *오픈북을 가지고 성실히 답변하는 착한 ai*
3. Retrieval-augmented LM
   1. 사용하는 이유: LLM의 지식은 금새 시대에 뒤쳐짐. 갱신이 어려움
   2. 기업 내부 정보와 같은 민감한 보안 정보는 언어모델 학습에 활용되지 않음
   3. 이것을 검색증강 언어모델이라고 부름.
   4. RAG의 결과는 검색 모델 성능에 의존함
   5. 즉, 검색 노이즈에 취약하다는 말임.
   6. Self-Attention을 사용하기 때문에, AI는 Context안의 정보를 이용하려는 경향성이 강함
   7. 따라서 검색에서의 노이즈가 Hallucination을 증가시킴
   8. LLM의 사전지식과 컨텍스트 간의 충돌이 발생 -> context 위의 Grounding 학습으로 대응

### Tool Usage
1. Agent: 센서로 환경을 지각하고, Actuator로 action하여 영향을 미치는 모든 것
   1. 환경 이해, 전략이 필수
   2. 이제는 의사 결정을 하는 매니저가 된 것임
2. 도구 사용 패러다임
   1. 모드 전환: 텍스트 실행 모드 - 도구 실행 모드
   2. 도구 사용 유도 기법: 프롬프트, 학습
3. Tool learning 방식
   1. 검색 엔진을 사용하기 위해 인간의 행동 모방
