## CNN
### CCN 모델
1. 완전 연결층(Fully-Connected Layer)
2. 합성곱 레이어(Convolution Layer)
   1. 입력 이미지를 필터와 연산하여 특징 맵(feature map)을 뽑아내는 모듈
   2. 1차원 구조로 변환하는 FCN과 달리 3차원 구조를 그대로 보존하면서 연산
   3. Convolution: 필터를 이미지 상에서 이동시키면서 내적을 반복 수행, 내적으로 구한 모든 값을 출력 제공
   4. 필터와 사진의 깊이는 반드시 동일해야한다
      1. 필터 내부의 값도 딥러닝이다. 가중치를 최적화한다.
   5. 특정 위치에서 필터와 동일 사이즈의 이미지 영역 간 내적한 결과 값
   6. `W^t * x + b`
   7. 그렇게 사진의 모든 부분을 필터 작업을 마친다
   8. 이 방법으로 활성화 맵(Activation Map)이 출력된다.
### CNN 모델 구조
1. 합성곱 레이어
   1. 모델 상수(파라미터)를 증가시키면?
   2. 비선형 블록(Conv[Linear] + ReLU[비선형 변환])과 함께하면 모델링 파워 향상
   3. 활성화 맵을 역산하면 이미지를 출력할 수 있다.
2. 필터 시각화
   1. 모델 내부 필터를 그림으로 출력해 보는 것임.
   2. 학습이 잘 됐는지 판단할 수 있음: 모델 디버깅
   3. 학습된 필터 시각화를 통해 각 모델이 학습한 정보를 이해 가능
      1. 선형모델: 필터는 각 카테고리의 템플렛(전형적 모습) 역할
      2. FCN: 다양한 템플릿 제공
      3. CNN: 계층별로 이미지의 지역적 템플렛(예시: 엣지, 색상 등)
3. 수용영역(Receptive Field)
   1. CNN 레이어는 이미지 작은 부분인 지역 정보를 추출하는데 유리하게 설계
   2. 이미지 활용하는 다양한 작업에서 이미지 전체 의미 파악 필요
   3. 따라서 지역 정보 + 이미지 전체의 맥락을 이해-활용하기 위한 설계가 필요함
   4. 수용영역: CNN이 이미지를 처리하면서 한 번에 볼 수 있는 영역의 크기
      1. 네트워크의 시야
      2. 네트워크가 깊어질수록 수용영역도 넓어짐 -> 폭 넓은 맥락 이해 가능
4. 중첩과 수용영역
   1. 고해상도 이미지 처리시, 많은 레이어를 통과해야함
   2. 이것은 연산, 비용, 학습 가능성을 고려하면 비효율적임
   3. 해법은 입력 사이즈를 줄이는 것임.
5. 풀링: 효율적 연산 및 위치 변화의 강건성 확보(*해상도를 낮춰서 작업하는 방식임*)
   1. 위치 변화 강건성: 입력 내 객체 위치가 다소 변해도 동일한 출력을 제공
   2. 사실상 저해상도 정보에 근거하여 작업 수행하므로 몇 화소 이동은 무시됨
   3. 맥스풀링: 정해진 커널 사이즈로 이미지를 나누어 각 영역 내 가장 큰 값을 선택하는 연산
6. 스트라이드 합성곱: 풀링 한계 개선
   1. 일반 합성곱: 필터를 1칸씩 이동하면서 연산 수행(출력값 계산)
   2. 스트라이드 합성곱: 필터를 스트라이드 값만큼 (S칸) 이동한 후 출력 연산
   3. 효과: 풀링 처럼 입력 해상도를 줄임 (연산 효율과 위치 강건성)
   4. 장점: 몇 칸씩 뛰어다닐지 알기 때문에, 이를 반영한 가중치 연산이 가능함. 정확도 상승
### CNN 기반 모델 변천사
1. 2010~2017년까지의 CNN 모델: 점점 성능이 향상돼서 2015년에는 사람과 비슷해짐
### AlexNet
1. AlexNet: 5개의 합성곱 계층과 3개의 완전연결 계층으로 구성된 8계층 CNN 모델
   1. 참 좋았고, 잘했고, 딥러닝 모델의 영감이 되었다. 고생했다!
   2. 단계를 거치면서 화소는 줄어들지만, 커널 개수는 늘어난다.
2. AlexNet 출력 사이즈 계산법[Conv1]
   1. 출력 해상 수 = 현재 레이어의 필터(커널) 개수
   2. W' = W - K + 2P / S + 1
3. AlexNet 연산비용 계산법[Conv1]
   1. FLOPs(연산량) = 총 연산(곱하기만 고려) = 출력 원소 수 * 출력 원소별 연산
### VGGNet
1. VGG 모델 구조 특징
   1. 16개 합성곱/연결층 레이어
   2. 단순하지만 깊은, 강력한 성능을 보임
   3. 그러나 연산량이 너무 비대함. 거구임. 뚱뚱이. 뚱보.
### ResNet: 현직 사용 모델. CNN의 영원한 국밥
1. 모델 구조 특징
   1. 합성곱 블록과 잔차 블록
   2. 잔차 블록은 블록입력을 그대로 출력에 더해주는 지름길 연결이 특징
2. ResNet의 등장 배경
   1. 배치 정규화 방식으로 10개가 넘는 레이어 학습이 가능해졌다.
   2. Residual Block(잔차 블록)의 핵심 아이디어는 다음과 같음
   3. 작은 레이어의 추정값(입력값)을 그대로 후속 레이어에 제공하여 최소한 작은 레이어 수준의 성능 보장
3. Residual Block(잔차 블록)
   1. 입력 X가 두 경로로 나뉘어 전달됨
   2. 마지막에 두 값을 더함
   3. 학습이 잘 안된다고 해도 최소 성능을 보장함
4. Bottleneck Residaul Block(보틀넥 잔차 블록)
   1. 연산 효율을 위해 보틀넥 잔차구조를 도입함
   2. 입력과 출력 해상도가 동일해야함
   3. 화소를 줄이고 다시 늘리는 과정을 거침
   4. 그래서 바틀넥 이라는 명칭이 붙은 것임
5. Stem 구조
   1. 기존 모델의 효율성 레시피를 잘 활용
   2. 입구 데이터 해상도를 25%로 줄이고 이후 잔차 블록 적용
   3. 여러 개의 FC 레이어를 제거하고 (GoogleLeNet에서 제안) 전역 평균 풀링을 사용
   4. 마지막 1개 FC만 사용
6. ResNet 성능
   1. ResNet-34 정도만 돼도 VGG-16 정도는 간단히 씹어먹음
   2. 성능은 물론이고, 연산량은 비교할수도 없이 빠름
   3. ResNet-50이 업계 표준임
7. 잘 알려진 ResNet 학습 레시피
   1. 모든 Conv 레이어 적용 시 배치정규화 수행
   2. Xavier 초기화 (He 초기화) 적용 / 그레디언트 소실 문제 다룸
   3. SGD + 모멘텀(0.9) 사용
   4. 학습 비율 0.1 적용, 단 Val 오류가 정체되면 1/10로 비율 축소
   5. 미니 배치 사이즈는 256 사용
   6. 웨이트 디케이 1e-5
   7. 드롭 아웃 미사용
### MobileNet
1. 목표: 모바일/임베디드 환경에서 구동 가능
   1. 기존 합성곱은 공간과 채널을 동시 처리하여 연산량이 과도하게 요구됨
   2. 공간과 채널을 두 단계로 분리하여 처리하면 해결이 가능함
   3. 이 방법으로 연산량이 기존 대비 약 9배 절감되었음 + 모델 상수 대폭 감소

# 2차시: 딥러닝 및 이미지 모델
1. CNN 만으로는 부족하다.
  - 순서가 중요한 데이터 처리 불가
  - 긴 거리 의존성 부족
2. CNN은 데이터 순서를 무시한다.
   1. 순차적 데이터의 순서 정보를 반영하기 어려움
### RNN
1. 순차적 데이터를 처리하기 위해 고안된 신경망 구조
   1. 순차적 정보 반영: 시간 및 순서의 흐름을 반영할 수 있다.
   2. 시계열/언어 데이터 적합: 문장, 음성신호, 센서 데이터 등
2. 순수(vanilla) RNN
   1. 선형변환, 바이어스를 모델상수/비선형(tanh)함수 추가로 구성된 단순한 형태
   2. 하이퍼 탄젠트를 사용하는걸 기억하라
3. RNN 입출력 구조
   1. One-ta-many: 하나의 입력에서 시간축으로 출력이 생성
   2. Many-to-One: 여러 시점 입력이 하나의 출력으로 압축
   3. Many-to-many: 입력과 출력이 시간축을 따라 1:1 혹은 n:m으로 맵핑
4. RNN 계산 그래프
   1. RNN은 히든을 거치며 그레디언트를 쌓아올린다.
   2. 단일 입력 - 시퀀스 출력
5. 단순 RNN의 한계
   1. 기울기 폭발 혹은 소실 발생
   2. 역전파의 기울기가 계속 곱셈으로 반영되기 때문임
### 대안 모델
1. LSTM(Long Short-Term Memory)
   1. 셀 상태, 게이트 유닛으로 구성
   2. 입력 게이트: 새로운 정보의 저장
   3. 망각 게이트: 과거 정보를 제거
   4. 출력 게이트: 셀 상태를 현재 은닉 상태로 출력
2. LSTM의 Cell state
   1. 기울기 전파 시 선형가중치의 곱 이외에 덧셈 형태로 전달하여 기울기를 장기적으로 보존 가능
## 긴거리 의존정: 어텐션/ViT
### 어텐션 메커니즘
1. 픽셀 거리와 상관없이 유사한 패치가 존재
2. 관련이 높은 패치, 낮은 패치 정보를 최종 결정에 반영하자
