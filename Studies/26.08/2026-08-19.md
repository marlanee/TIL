# NEW 강사님 - 파운데이션 모델
1. 1세대 GAN: 적대적 생성 신경망
   1. 사용해보니, 생성자가 이미지의 노이즈를 바꾸면 이미지도 바뀜
   2. 이것을 활용하면, 이미지의 특징을 바꿀 수 있다는 소리임
   3. 그러나 생성자-판별자의 수준 차이가 심하면 모드 붕괴 발생
2. 2세대 Diffusion 모델
   1. 순방향 - 역방향 방식: 노이즈 생성 - 제거
   2. 특징: 노이즈를 예측하고 제거한다. 
   3. 이미지를 단계적으로 생성하기 때문에 모드 붕괴가 발생하지 않음
   4. 또한 노이즈를 제거하는 각 단계마다 사용자가 작성한 텍스트를 참고함
   5. 한계: 기억의 개념이 없어서 결과물이 매번 달라짐. 문맥 이해도 부족함. 그리고 느림
3. LDM의 동작 과정(Latent Diffusion Model)
   1. Encoder(압축기)로 거대한 이미지를 아주 작은 잠재 벡터로 압축함
   2. 잠재 벡터의 노이즈를 섞고 지우는 작업을 진행함
   3. Decoder(복원기)를 사용해 선명한 이미지로 복원
### 멀티모달
1. 멀티모달: 텍스트, 이미지, 오디오, 비디오 등 서로 다른 형태의 데이터를 함께 이해하고 처리하는 AI 기술
2. CLIP: 2021년 OpenAI가 발표한 인공지능 모델
   1. WIT라는 4억개의 이미지-텍스트 쌍을 기반으로 학습
   2. 대조 학습을 기반으로 학습을 진행함
   3. 이미지와 텍스트를 나란히 두고 서로 맞는지 비교하며 학습
3. CLIP 동작 방식
   1. 이미지 인코더와 텍스트 인코더가 각각 사진과 글을 벡터로 변환
   2. 만들어진 모든 이미지 벡터와 텍스트 벡터를 각각 쌍으로 보면서 정답이면 가깝게, 오답이면 멀게 설정
4. Stable diffusion
   1. LDM + CLIP
   2. LDM 구조 덕분에 슈퍼컴퓨터가 아니어도 실행 가능
5. 지식 증류(knowledge Distillation)
   1. 거대 모델의 힘을 빌려옴. 거대 모델의 출력을 label로 사용
