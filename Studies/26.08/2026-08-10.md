# 워드 임베딩과 순환신경망 기반 모델(RNN & LSTM)
1. 학습 시작
  1. 언어를 어떻게 숫자료 표현할까?: One-hot encoding, workd embedding 등 기본 아이디어 이해
  2. 언어에서 '순서(문맥)'는 왜 중요할까?
2. 원-핫 인코딩
  1. 원래는 쪼갤 수 없는 기호인 단어.
  2. 벡터 공간 관점에서는 숫자 벡터로 표현이 가능하다.
3. 원-핫 인코딩의 문제점
  1. 비슷한 용어를 구분할 수 없다.
  2. 예시: "갤럭시 핸드폰", "갤럭시 스마트폰"
  3. (심화)이유: 검색 쿼리 벡터와 대상이 되는 문서 벡터들이 서로 직교하여 유사도 측정 불가.
  4. 차원의 저주라는 한계가 존재한다. 
  5. 고차원의 희소 벡터를 다루기 위해선 많은 메모리가 필요하고 데이터가 희소해져 활용이 어렵다는 뜻임.
4. 워드 임베딩: 주변 단어들을 활용해보기
  0. 모든 단어를 실수로 표현함
  1. 단어를 주변 단어들로 표현하면, 많은 의미를 담을 수 있다.
  2. Skip-grams(SG): 중심 단어를 통해 주변 단어 예측하기.
  3. CBOW: 주변 단어를 통해 중심 단어 예측하기.
5. Skip-Gram vs CBOW
  1. Skip-Gram: 적은 데이터도 가능, 희귀 단어나 구 표현에 강함. 학습 속도 빠름
  2. CBOW:
6. 순차적 데이터란 무엇인가?
  1. 순차적 데이터란, 데이터가 입력되는 순서와 이 순서를 통해 입력되는 데이터들 사이의 관계를 구한다.
  2. 순차적 데이터는 다른 데이터와 구별되는 특징들이 존재한다.
    1. 순서가 중요하다. 예시: 나는 너를 시사랑해, 너는 나를 사랑해는 다르다.
    2. 장기 의존성: 과거의 정보가 현재나 미래에 영향을 준다.
7. 전통적인 인공신경망: MLP. CNN등은 고정된 길이의 압력을 받아 가변 길이의 데이터를 처리하기에 적합하지 않다.
8. RNN 아키텍쳐 설명
   1. 전통적인 신경망과 달리, RNN은 이전 시점의 정보를 담는 hidden state를 가지고 있다.
   2. RNN은 한 번에 하나의 요소를 처리하고, 정보를 앞으로 전달한다.
   3. RNN은 hidden state를 유지하면서 가변 길이 데이터를 처리할 수 있다.
   4. RNN의 출력은 과거 입력에 영향을 받는다는 점에서, feedforward 신경망과 다르다.
9. RNN의 한계: 기울기 소실 문제
   1.  기울기 소실은 역전파 시 앞쪽 층의 기울기가 0에 가까워져서 장기 의존성 학습이 어려워지는 현상
   2.  역전파 과정에서 작은 값들이 계속 곱해져서 파라미터들이 장기 의존성을 학습하지 못한다.
10. LSTM: 기울기 소실 문제를 해결하기 위해 제안된 RNN
11. LSTM의 특징
    1.  시점 t에서 RNN은 길이가 n인 벡터 hidden state ht와 cell state Ct를 가진다.
    2. Forget gate: 이전 cell state에서 무엇을 잊을지 결정
        1.  0을 가진 element를 넣어서 잊을 것을 결정함
    3. Input gate: 새 정보 중 얼마나 cell state에 쓸지 결정
    4. New cell content: cell에 기록될 새로운 후보
    5. Output gate: cell stae중 얼마나 hidden state로 내보낼지 결정

# 언어모델
1. 언어모델이란?
   1. 한 문장의 확률은 각 단어의 조건부 확률들의 곱으로 표현할 수 있다.
2. 대표적인 언어모델 - N - gram 언어모델
   1. 빈칸 단어 앞의 N개만 참고해서 예측하는 모델
3. Seq2Seq
   1. RNN과 LSTM의 진화 버전임.
   2. Encoder와 Decoder로 이루어짐
   3. Encoder: 입력 문장에 담긴 정보를 인코딩함
   4. Decoder는 인코딩된 정보를 조건으로 하여 타겟 문장을 출력한다.
4. Seq2Seq의 다양한 적용
   1. 기계번역 외에도 다양한 태스크에 적용할 수 있다.
   2. 요약, 대화, 코드 생성 등
   3. 한계: 되돌리기가 불가능
   4. 한계 극복: Teacher Forcing
   5. 모델이 스스로 예측한 단어 대신 정답 단어를 디코더 입력으로 강제로 넣어줌. 훨씬 학습이 빨라짐.
5. Seq2Seq의 토큰 출력 방법(Beam Search)
6. Beam Search
   1. 매 단계마다 k개의 가장 유망한 후보 유지
   2. 후보가 EOS에 도달하면 완성된 문장으로 리스트 추가
   3. EOS 문장이 충분히 모이면 탐색 종료
   4. 각 후보들의 점수를 로그 확률로 합으로 구해 최종 선택
7. Seq2Seq의 한계: the bottleneck problem
   1. 인코더는 입력 문장 전체를 하나의 벡터로 요약한다. 마지막 hidden state에 문장의 모든 의미 정보가 담긴다.
   2. 한 줄 요약하다보니 정보 손실이 생긴다. 이를 bottleneck problem이라고 한다.
   3. 자본론을 한 줄 요약하는 놈이 다음 문장을 맞출리가 없다.
8. Attention: 원본을 검색 후 스포트라이트 점수를 매김. 점수가 높은 곳에 확률 가중치를 부여하고, 최종적으로 가장 높은 확률 단어를 뱉음
9. Attention: Query와 Values
   1. Seq2Seq에서 attention을 사용할 때 각 decoder의 hidden state와 모든 encoder의 hidden states간의 관계를 Query와 Values의 관계로 볼 수 있다.
   2. 이 관점에서 Attention 과정을 정리하면
   3. Query와 Values 사이 유사도 점수 계산
   4. Softmax를 통해 확률 분포 얻기
   5. 분포를 이용해 values를 가중합 -> context vector
10. Attention의 효과
    1. NMT 성능 향상
    2. BLEU score: 기계 번역의 출력이 사람 번역과 얼마나 비슷한 지 평가하는 지표
    3. 해석 가능성: attention 분포를 통해 decoder가 어떤 단어를 생성할 때, 입력 문장의 어느 부분에 집중했는지 알 수 있다.
    4. 정렬(Alignment): decoder가 필요한 입력 단어에 자동으로 집중하기 때문에 따로 뭐가 필요 없다.

# Self-Attention
1. RNN의 한계점
   1. 장기 의존성: 장기 기억력이 점점 낮아짐
   2. 병렬화: 시퀀스 길이 만큼의 단계가 필요해서 병렬화 불가능
2. 그것을 해결한 Attention
   1. 각 단어의 표현을 query로 두고 value 집합으로부터 필요한 정보를 직접 불러와 결합함
   2. 이런 Attention 메커니즘을 encoder-decoder 간이 아닌 한 문장 내부에서 적용한다면 어떨까?
   3. 그렇게 탄생한게 Self-Attention임.
3. Self-Attention
   1. Query 벡터: 단어 i가 다른 단어로부터 어떤 정보를 찾을지를 정의하는 벡터
   2. Key 벡터: 단어 i가 자신이 가진 정보의 특성을 표현하는 벡터
   3. Value 벡터: 실제로 참조되는 정보 내용을 담고 있는 벡터
4. Self-Attention의 햔계
   1. 순서 정보 부재: 단어 간 유사도만 계산, 단어 순서 고려 x
   2. 비선형성 부족: 복잡한 패턴이나 깊은 표현력 담기 힘듦
   3. 미래 참조 문제: 단어를 동시에 보기 때문에, 아직 생성되지 않아야 할 미래 단어를 참조함
5. Self-Attention의 한계 해결
   1. Positional Encoding: 위치 벡터를 정의해, 단어 임베딩 값에 더해 최종 입력으로 사용함
   2. Feed-Forward Network 추가하기
      1. 각 단어 출력 벡터에 Feed-Forward Network 을 추가해 깊고 비선형적 표현을 확장한다.
   3. Masked Self-Attention: 미래 단어 예측 방지
      1. 미래 단어 항목을 마이너스 무한으로 설정해서 계산에서 제외
6. Self-Attention 정리
   1. 문장 내 모든 단어가 서로 직접 상호작용함
   2. 장거리 의존성을 효율적으로 포착
   3. 병렬 처리가 가능
   4. 한계 해결 방법 3가지: Positional Encoding, Feed-Forward Network, Masked Self-Attention

2. Encoder 모델: 사전학습

   2. 입력 단어를 mask 토큰(빈 칸)으로 치환해서 예측하도록 학습함
3. BERT
