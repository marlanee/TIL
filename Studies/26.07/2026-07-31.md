# Bootstrap
뭔지 모르지만, 부트스트랩 사이트에 들어가야 된다고 한다.  
다운받지 않고 홈페이지의 코드를 복사해서 집어넣었더니 폰트가 바뀌었다.  
CDN (Content Delivery Network)를 사용한다고 한다. 여러 서버들을 각 국에 설치해서 속도를 높인다.  
홈페이지에서 파일을 다운받았더니 프로그램이 아닌 파일들이 있었다.  
디자인에 관여하는 css 파일과 움직임을 관리하는 자파 파일이 있었다.  
다운보다는 CDN으로 홈페이지 코드 복사를 권장한다고 한다.  

### Bootstrap 기본 사용법
- 특정한 규칙이 있는 클래스 이름으로 스타일 및 레이아웃이 미리 작성되어 있음
  - Ex) `mt-5` (property)(Sides) - (Size)

### Bootstrap 적용 전/후 비교
- 일부 스타일이 바뀜

### Reset CSS
모든 HTML 요소 스타일을 일관된 기준으로 재설정하는 간결하고 압축된 규칙 시트.  
웹 브라우저마다 기본 폰트가 다를 수 있으므로, 폰트를 동일하게 설정하려고 사용.  
폰트를 초기화 후 시작.  
---
### Normalize CSS
- Reset CSS 방법 중 대표적인 방법
- 웹 표준 기준으로 브라우저 중 하나가 불일치 한다면 차이가 있는 브라우저를 수정하는 방법
