### API
What is API?  
- API의 동작 방식은 식당의 주문 과정에 비유할 수 있음
  - 손님이 음식의 조리 과정을 몰라도 주문할 수 있듯, 클라이언트는 서버 내부 처리 과정을 몰라도 API를 통해 요청을 보내고 응답을 받을 수 있음
  - API가 점원과 같은 역할을 한다.
- Request와 Response
  - 클라이언트: 서버에 요청 (request)를 전송 (parameter)
  - 서버: 요청을 처리한 후 응답 (response)를 반환
  - URL: 전송을 처리할 주소
- HTPP 메서드
- 상태 코드
  - 200: 너가 요청한 것 정상 처리했어
  - 404: 너가 찾는 것 없다 / New era!
  - 500: 개발자야, 너가 잘못 만들었다. 오류다.
- requests 라이브러리
  - request.get(): 서버의 응답을 Response 객체로 반환
  - 아무리 못해도 status_code, json()는 알고 있어야 된다.
- API 키 보안
  - 다른 곳에서 사용하지 못하게 보안을 신경써야함
  - .env를 gitignore에 집어넣어야 한다.
  - API 키는 env 파일에서 얻어와서 읽는다. 
- *나, 리스트 컴프리헨션 숙달해야된다.*

### 데이터 다루기
1. NumPy
   1. 배열 (ndarray): 숫자 데이터를 처리하는 NumPy의 다차원 자료구조
   2. 벡터화: 반복문을 직접 장성하지 않고 배열 전체에 연산을 적용
      1. 아, Numpy는 벡터 성질이니까 바로 리스트 곱셈이 가능하구나
   3. 벡터화된 연산으로 일반적인 반복문보다 빠르게 처리 가능
   4. 집계 함수: mean, sum, min, max 등 사용 가능
   5. 배열 만들기
      1. np.array(리스트): 리스트롤 NumPy 배열로 변환
      2. np.arange(n): 0 ~ n-1 까지의 정수로 배열 생성
      3. np.zeros(n), np.ones(n): 0또는 1로 채운 배열 생성
      4. np.linspace(a, b, n): a부터b까지 같은 간격의 값 n개 생성
      5. .ndim, .shape: 몇 차원인지, 차원의 크기가 몇인지 알려줌 / fucking dimension
   6. 2차원 배열 만들기
      1. .reshape(a, b): a행 b열로 나온다.
      2. -1: 전체 원소 수에 맞춰 해당 차원의 크기를 계산
      3. axis=0: 열별로 값을 집계
      4. axis=1: 행별로 값을 집계
   7. 브로드캐스팅: 크기가 다른 배열을 연산할 수 있도록 작은 배열을 확장
   8. 조건부 필터링
      1. 배열[조건]: 조건이 True인 위치의 원소만 추출
      2. &: 두 조건을 모두 만족
      3. 정렬: np.sort(배열)
      4. [::-1] 역순
      5. np.argsort(배열): 배열을 오름차순으로 정렬한 인덱스 반환
2. Pandas: 표 형태의 데이터를 다루며, NumPy 배열을 활용함
   0. Pandas: 이름표 달린 NumPy + 엑셀의 연산 기능
   1. NumPy의 한계 -> Pandas로 해결!
      1. 여러 타입이 있으면 전부 문자열로 형변환
      2. 열 이름이 없음
      3. 비어 있는 데이터 표현이 어려움
   2. Data Frame: 시리즈들의 모음. 표로 보임
      1. 열마다 다른 자료형을 사용할 수 있음
      2. 같은 인덱스를 공유하는 여러 Series로 구성
      3. 조회, 필터, 집계, 분석 가능
      4. 조회 메서드: head(n), tail(n), info(), describe(), shape, dtypes, columns
      5. info()가 진짜 중요함
3. NumPy vs Pandas
   1. Pandas: 데이터를 읽고 정리하고 탐색 (전처리)
   2. NumPy: 정리가 끝난 순수 숫자 행렬을 계산 (학습)
