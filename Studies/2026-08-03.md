# Web: Responsive Web
- UX (User Experience): 만족도 개선, 최적화
- UI (User Interface): 디자인 요소 개발 및 구현
  - 와이어프레임, 디자인 시스템, 프로토타입
- Desire Path: 길을 예쁘게 꾸며도 지름길로 다니는 사람들. UI가 예뻐도 UX가 구리면 외면 받는다.
---
### Bootstrap Grid system
웹 페이지의 레이아웃을 조정하는 데 사용되는 12개의 컬럼으로 구성된 시스템  
- 약수가 많은 12로 컬럼 개수를 정했다.
- Grid system: 12칸 칸 나눠주기 게임
- Grid system 기본 요소
  1. Container: Column들을 담고 있는 공간
  2. Column
  3. Gutter
  4. Margin
- 1개의 row 안에 12개의 column 영역이 구성됨
  - 각 요소는 12개 중 몇 개를 차지할 것인지 지정됨
- *신기하다. 화면 크기가 어떻든 12개 칸의 분배 비율로 결정된다*
---
### Gutters
- 좌, 우는 padding으로 밀어낸다. 커지는 만큼 column의 크기가 줄어듦
- 상, 하는 margin으로 밀어낸다.
  - 좌, 우는 margin으로 못 밀어낸다. 밀어내면 container의 크기를 벗어나기 때문.
- Gutter의 활용
---
### Grid system for responsive web
- 12개의 column과 6개의 breakpoints를 사용하여 반응형 웹 디자인을 구현
### Breakpoints (분기점)
- 화면 너비에 따라 xs ~ xxl 까지 있다
- 각 breakpoints마다 설정된 최대 너비 값 이상으로 화면이 커지면 grid system 동작이 변경됨
- offset설정도 가능하지만, 화면이 커질 때 계속 반영되므로 재설정이 필요함. 내가 해봤음.

### CSS Layout 종합 정리
- 에어 비엔비 뜯어보기.
- Grid 시스템이 들어가있다. 역시 12개의 column
  - 건물의 뼈대. 큰 틀을 잡을 때 사용
- Flexbox: 방 안의 가구. 구역 내부의 디테일
- Position: 벽에 붙인 스티커
